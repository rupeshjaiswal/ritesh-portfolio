## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/rupeshjaiswal/ritesh-portfolio.git
```

Go to project folder:

```bash
cd ritesh-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
